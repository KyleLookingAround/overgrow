# The page designed as one, on every device

- **Map first.** The map is the biggest thing on every screen, phone to ultrawide.
- **The panel is a sheet.** On a phone it rests at three heights; the goal and the speed are in thumb reach.
- **Fullscreen.** A button at the map's corner where the browser has it; add to the home screen on iPhone.
- **One look.** One type scale, one set of colours, and every control readable in light and dark.

History: the shell redesigned as one for every device, with a fullscreen mode and a home-screen manifest.
