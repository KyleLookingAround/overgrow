# Saving

The game saves on the device and carries on exactly where it was, the random stream included: the format and its migrations in `src/sim/save.ts`, the generator in `src/sim/random.ts`, the device's side in `src/app/storage.ts`, and when it saves and loads in `src/app/main.tsx`.

- **The format** (`src/sim/save.ts`): versioned JSON (`SAVE_VERSION`, 1 today) of the whole state less what's runtime only: the seed, the main stream's state (`Rng.state()`, `src/sim/random.ts`: saved and restored exactly, though no system draws from it yet, since each draws its own dice from the seed and the hour), the hours, level and speed, the household, the graph, the last tick's flows, the activities, the sealed levels (the ladder), upgrades, laws, goals, settings and what's been seen. `fromSave()` checks what it reads and throws a `SaveError` naming what's wrong; a `load` command that fails leaves the game as it was.
- **Migrations.** `MIGRATIONS[n]` turns a version-n save into version n+1, and `migrate()` runs the chain one step at a time; a save from a newer version is refused. There are no steps yet: the first change to the saved shape adds `MIGRATIONS[1]` and raises `SAVE_VERSION`. Never rename or remove a saved field; add one with a default and a step. `src/sim/save.test.ts` proves a save round-trips and plays on identically, and that the chain runs; `src/sim/index.test.ts` saves and loads in the middle of a two-year run. The save fixtures and the `migrate` check come with the first release (part 15).
- **Where it's kept** (`src/app/storage.ts`): `localStorage['overgrow-save-v1']`, the one key, every call guarded so a full or blocked store never stops the game. A move to IndexedDB once a save passes 1 MB changes only that file.
- **When** (`src/app/main.tsx`): after a new game starts, every game day, after any command that isn't a tick, when the page is hidden, and on leaving (the last save text, written at once since the page can't wait for the worker; if the page closes before the save started on hiding comes back, up to a game day's play since the last one is lost). On opening, a save is loaded; a save from a newer version of the game is left alone and the session doesn't save over it, and any other unreadable save is replaced by a new game.
