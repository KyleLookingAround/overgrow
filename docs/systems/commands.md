# Commands and snapshots

Every change to the game is a command (`src/sim/commands.ts`), from the player, a manager or the bot alike; `createSim()` in `src/sim/index.ts` applies them and returns a snapshot (`src/sim/state.ts`) with the activities the map animates (`src/sim/activity.ts`). On the page the sim runs in a worker (`src/app/sim.worker.ts`, with `src/app/sim-client.ts` as the page's end), snapshots cross as deltas (`src/app/delta.ts`), and `src/app/bench.ts` is the check-only synthetic scene.

- **Commands.** `tick` (whole steps), `new-game` (a seed, and a speed, 1× by default), `load` (a save's text), `speed`, `plan`, `policy` and `law` (set a lever a system declared on a node), and `upgrade` (bought from the system that offers it). A lever command is refused if the node or lever isn't there; otherwise each system's `command` hook is asked in turn, and the first that answers can refuse it with a reason. An upgrade nobody sells is refused. A refusal leaves the game as it was and says why in the snapshot's `rejected`. Later commands keep the shape: a `type` and what it acts on.
- **The snapshot** carries the seed, the hours, the level and its step, the speed, the household's money, the carbon the level has put into the air, the graph's `rev`, every node (copied, so a later tick can't change it), the edges, the flows of the last tick command (merged by ends), the activities, and `rejected` and `errors`.
- **Activities** (`src/sim/activity.ts`): who is doing what, where, from when to when, with the places passed on the way and anything carried. The map animates from them; `placeAt()` gives where an actor is at a game hour. An activity never changes once started: a system ends it and starts another with a new id. The first real one is the gardener's (part 3).
- **The worker boundary.** The page runs the sim in a Web Worker (`src/app/sim.worker.ts`); `src/app/sim-client.ts` is its end. Snapshots cross as deltas (`src/app/delta.ts`): the whole snapshot after a new game, a load or a change to the graph, and otherwise only the stocks, levers and totals that changed (at the garden, each hour the soils' water, and once a day the air's `weather` lever and the soils' carbon, nutrients and health) and the activities that started (or were cut short; one that reaches its end is dropped on both sides). `src/app/delta.test.ts` rebuilds every snapshot of a long run from them exactly. Each reply carries how long the worker took to write the one before, and the client keeps how long reading and patching took, for the speed budget. `src/app/bench.ts` is the check-only synthetic scene the `scene` check measures with.
