# The runbook, from Final Call, then reworked with the owner (#1) · 28 Sep 2026

- **Numbers:** estimate $25 for this PR and the spec together; the session's cost wasn't reported while this was written (a missing reading means not yet known). About 330k of 1M context by the rework's end. Session started 18:02 UTC, PR opened 18:19 as a straight port; the owner then joined and the setup was reworked in place. Five commits in all. No merges from `main` needed. One real bug found by looking at a screenshot: the phone panel pushed off-screen by the canvas, which the `build` check's overflow test didn't catch because the body hides overflow.
- **Went well:** reading Final Call's tools and five playbooks once, then writing each file for Overgrow rather than copying, kept the port small. The fresh review before opening caught eight real problems in the port, including a Description job named `check`, like the Checks job, which could have satisfied a required `check` status by itself (the same clash is in Final Call). Pausing to design the systems and the ladder with the owner before writing the scaffold meant the architecture (a scale-free graph, the sim in a worker, real mechanisms with rough numbers) went in once, not as a rewrite.
- **Lessons:**
  - A port from a sister repo carries its architecture by default. Ask the owner what to keep before writing the setup, not after: here the one-page, no-dependencies rule came across unquestioned and was replaced the same afternoon. → The runbook record now lists what was changed rather than copied, and why (`docs/decisions/ADR-2026-09-28-runbook-from-final-call.md`).
  - "No overflow" is not "in view": with `overflow: hidden` on the body, an element pushed off-screen passes a scroll-size test. → The `build` check now asserts the panel's bounding box is inside the viewport (`tools/checks/build.mjs`).
  - The graph check fails on any doc that names a file that doesn't exist yet, which a decision record listing what was left out does on purpose. Name left-out files without their folder, as that record does. No tool change: the check is right to be strict about links.
  - Final Call's `graph.mjs` never matched `.github/…` links (a `\b` before a dot), and its Description job shares the `check` name; both fixed here and worth porting back by one of its own sessions.
