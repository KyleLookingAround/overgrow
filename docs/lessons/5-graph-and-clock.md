- **Lessons:**
  - Timing a worker message with the two sides' clocks measures the page's queue, not the copy: with software WebGL at 9 frames a second every "copy" read about 115 ms. Time the first read of `event.data` (when the browser rebuilds the message) and the patch on the page, and the `postMessage` call in the worker, separately. `docs/SYSTEMS.md` ("Speed budget") says how the figures were taken, so later parts measure the same way.
  - A browser check samples frame by frame (`requestAnimationFrame`, with a time limit), not on wall-clock timers: CI's software WebGL runs at 5–10 frames a second, and the one fixed 200 ms read left in `layout` failed there. → `feature` step 4 ("waits for what it asserts").
  - `tools/join.mjs` takes a system's files from the first paragraph of its note only. → `feature` step 5 now says to name every file there.
  - An activity that reuses an id across trips vanishes under deltas; the rule (an activity never changes once started, a new trip is a new id) is in `docs/systems/commands.md`.
